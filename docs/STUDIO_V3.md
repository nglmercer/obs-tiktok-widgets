# Studio v3 compatibility notes

The supported authoring interface is now [Studio v4](UI_V4.md). Installed users edit plain HTML/CSS/JavaScript and need no Node or framework toolchain. The original v3 build-provider internals remain for compatibility with existing source projects and published releases; new TS/React projects and toolchain installation are disabled.

Older validation evidence is retained in [VALIDATION.md](VALIDATION.md). It records the environment and checks actually executed; it does not imply that historical framework starters remain available to installed users.
